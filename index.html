AKIRA Dev Tools

Five single-file, dependency-free Python 3 CLI tools. Stdlib only. Tested. No pip, no supply chain.

apidiff

Capture a baseline from any HTTP endpoint, then diff the live response to catch breaking changes. Auth & POST supported.

48 tests

secretscan

Scan a repo for hardcoded secrets before you commit. Read-only, never modifies files.

13 tests

jsonl2csv

Convert JSON / JSONL to CSV with explicit field control. Handles ragged records.

13 tests

dupfind

Find duplicate files by content hash. Read-only by design — it never deletes anything.

18 tests

envcheck

Lint a .env file against a template or schema. Reports missing/extra keys without ever printing secret values.

30 tests
Honest positioning. These are intentionally small. They are not meant to replace mature projects (gitleaks, trufflehog, jq, fdupes, rdfind). Their niche: one file you can read in a minute, drop in, and trust — for air-gapped, locked-down CI, or throwaway scripts where installing packages is a burden. If you need deep rule sets or high volume, use the established tools.

Quick start

# each tool is a single .py file — copy it and go
python3 apidiff.py    --help
python3 secretscan.py --help
python3 jsonl2csv.py  --help
python3 dupfind.py    --help
python3 envcheck.py   --help

Run the tests

python3 test_apidiff.py     # 48 passed
python3 test_secretscan.py  # 13 passed
python3 test_jsonl2csv.py   # 13 passed
python3 test_dupfind.py    # 18 passed
python3 test_envcheck.py   # 30 passed
